過去の任意のコミットの状態に一時的に戻り、そのコミット内容の修正や分割・追加を行える機能。

・過去のコミット時点のファイル時点のファイル変更をやり直したり、
　ファイルを追加・削除できる。

・ひとつのコミットに複数の変更をまとめてしまった場合、
　細かく分割して別のコミットに分けることができる

・コミットの日付や時刻だけを後から変更することも可能。

# １　対話型リバースを開始する
　　　修正したいコミットよりも古いコミットのハッシュタグを指定してコマンドを実行する。
　　　bash 
     git rebase -i <コミットハッシュまたは親コミット>

# ２　pickをeditに書き換える
　　　表示されるエディタの一覧から、修正したい行のpickをeditに書き換えて保存・終了する。

# ３ コードやファイルを修正する
　　 Gitがその過去のコミットの場所で止まるため、
　　 通常通りファイルを編集し、変更をステージングする。 

# ４　変更をステージングしてコミットを上書きする
　　　bash 
     git add <修正したファイル名>
     git commit --amend

# ５　リベースを続行する
　　　残りの処理を再開する
　　　bash 
     git rebase --continue
