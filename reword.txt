過去のコミットメッセージを修正(変更)できる機能。

コミットの変更内容(ファイル修正、コードの追加・削除など)はそのままで、
メッセージのタイポ(誤字脱字)を直したいときや、より分かりやすい文章に書き換えたい時に使う。

# １　修正したいコマンドが含まれる範囲を指定してコマンドを実行する
　　例）現在から3つ前までの履歴を表示したい場合:
　　bash 
    git rebase -i HeAD-3

# ２　エディタでpickをreword(またはr)に書き換える　
　　画面が開いたら、メッセージを変更したいコミットの行の先頭にある
　　pickという文字をrewordに変更して保存・終了します

# ３　新しいメッセージを入力する　
　　　保存すると、自動的にメッセージ編集画面が新しく開くので、
　　　新しいコミットメッセージを書き込んで保存すれば完了。

注意点　rewordを実行すると、コミットメッセージが変わるため
　　　　コミットID(ハッシュ値)が新しく生成し直される。

　　　　すでにGitHubなどのリモートリポジトリにpush済みのコミットに対して行うと、
　　　　他の開発者の環境とコンフリクト(競合)を起こす原因になるため、
　　　　まだpushしていないローカルのコミットに対して行うのが安全とされる。
