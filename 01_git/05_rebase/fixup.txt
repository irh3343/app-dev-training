git commit --fixup は、
過去の特定のコミットに対する修正差分を綺麗に統合(マージ)するための便利な機能。

## 1　修正内容をステージングする
　修正したファイルをステージングエリアに追加する
　bash
　git add <修正ファイル>

## 2　fixupコミットを作成する
　まとめたい(趨勢対象)の過去のコミットハッシュを指定してコミットする
　bash
　git commit --fixup <対象のコミットハッシュ>

　これにより、コミットメッセージの先頭に自動でfixup! が付いた専用のコミットが作成される

## 3　autosquashで履歴をまとめる
--autosquashオプションを付けてインタラクティブベースを実行する
bash
git rebase -i zutosquash <基準となるコミットの親ハッシュ>

自動的にfixup!対象のコミットの直下に移動して、コマンドがfixupに設定されるため、
そのまま保存してエディタを閉じれば統合が完了する。
